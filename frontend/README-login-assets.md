# Login assets

The image files in `public/images/` are **placeholders** generated so the login
page can be built and previewed. Replace each one with the real asset, keeping
the same file name:

| File | Used for |
| --- | --- |
| `msu-seal.png` | MSU seal on light backgrounds (mobile header) |
| `msu-seal-outline.png` | MSU seal with cream outline for the maroon panel |
| `client-logo.png` | Client logo on light backgrounds |
| `client-logo-outline.png` | Client logo with cream outline for the maroon panel |
| `login-bg.jpg` | Full-viewport page background photo |

`login-bg.jpg` is optional: when it is missing the CSS gradient on
`.signin-page` is shown instead, and no broken image appears.
